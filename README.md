# 🐶 dog-cam
1. Установка: `npm install`
2. Запуск: `npm start` (порт по умолчанию 3000, меняется через `PORT=3030 npm start`)
3. Откройте сайт и войдите по своему логину и паролю. Если трансляция идёт, видео откроется само, если нет — нажмите «Начать трансляцию».
4. Зрителей сколько угодно: откройте сайт на других устройствах или вкладках под тем же логином.
5. ⚠️ На телефоне камера работает только по HTTPS (GitHub Pages или деплой с SSL).
